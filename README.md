# 무신사지마

Chrome·Edge 브라우저에서 쓰는 체험단 신청 도구의 무료 시범 운영용 관리 화면입니다.

[관리 화면 열기](https://m0000000n.github.io/musinsazima/)

웹 화면에서 확장 프로그램 설치, 무신사 로그인 확인, 필수 동의, 사이즈와 배송 설정을 차례로 진행합니다. 비밀번호와 쿠키는 서버로 보내지 않습니다. 신청 조건과 진행 상태는 각자의 브라우저에 저장합니다.

확장 프로그램은 압축을 풀어 직접 불러오는 시험 배포 방식입니다. 확장 코드 업데이트 때는 새 파일을 받고 다시 로드해야 합니다. 실제 계정의 신청 자격과 무신사 화면 변경에 따라 처리가 중지될 수 있습니다.
